# Stella Web IM 完整项目开发文档（最终定稿版）

## 一、项目概述

### 1\.1 项目简介

本项目是一套基于 React \+ Node\.js 搭建的**轻量化、高稳定性、多端兼容 Web 即时通讯系统**。
项目核心解决行业常见痛点：**浏览器多标签 WebSocket 重复连接、前端请求竞态混乱、Token 过期雪崩、多窗口状态不一致、离线消息丢失、网络环境不稳定**。

整体架构严格遵循：**高内聚、低耦合、单一职责、分层解耦、优雅降级、容错自愈**。

### 1\.2 完整实现功能清单

1. **SharedWorker 全局唯一 WebSocket 长连接**

2. **WebSocket 登录鉴权机制（未登录用户禁止握手连接）**

3. **WebSocket 断线重连：指数退避 \+ 随机抖动防雪崩**

4. **WebSocket 彻底失效自动降级 HTTP 增量轮询**

5. **多标签页面抢占式单例机制（Worker 优先，StorageEvent 降级）**

6. **用户登录、退出、跨标签全局同步登出**

7. **完整好友体系：用户添加好友、双向好友关系、双向聊天**

8. **后端定时系统通知：每 2 分钟推送服务端时间公告**

9. **消息双源策略：HTTP 拉历史 \+ WS 推实时增量**

10. **精准全局通知系统：会话内静默更新、会话外 Toast 弹窗**

11. **企业级 Axios 请求治理**

    - 401 Token 无感刷新（队列等待、无感知续期）

    - 请求并发队列限流

    - 竞态请求自动取消

    - 重复请求去重

    - **请求失败自动重试 \+ 指数退避随机抖动**

12. **全局状态解耦：Context 只管理能力，不存储业务数据**

13. **完整容错、降级、自愈机制**

### 1\.3 技术栈

- 前端：React18 \+ TypeScript \+ Context API \+ SharedWorker

- 后端：Node\.js \+ Express \+ WebSocket

- 存储：LocalStorage

- 通信：HTTP、WebSocket、Worker 线程通信、StorageEvent 跨页通信

## 二、系统整体架构设计

### 2\.1 四层分层架构（单向依赖、高内聚低耦合）

1. **底层通信兼容层**
负责全局长连接、跨页同步、降级兜底

    - SharedWorker（主通信）

    - HTTP 轮询（WS 降级兜底）

    - LocalStorage \+ StorageEvent（多标签降级、跨标签登出）

2. **全局能力中台层**
全局唯一底层能力，业务层可复用

    - 全局 WebSocket 连接管理器

    - 全局 Axios 请求治理中台

    - 全局用户会话登录管理器

    - 全局多标签单例抢占管理器

3. **全局状态调度层（Context）**
只管理**能力、订阅、状态**，**永不存储业务数据**

    - WS 全局连接状态

    - 双订阅总线（页面消息订阅 \+ 全局通知订阅）

    - 全局活跃会话 ID

    - 全局登录用户状态

4. **页面业务层**
所有业务数据**页面本地私有化**

    - 登录页、首页、好友页、消息聊天页

    - 页面挂载 HTTP 初始化历史数据

    - 页面运行 WS 增量更新

    - 页面卸载销毁数据、取消订阅、释放内存

### 2\.2 架构设计核心思想

1. **能力全局、数据局部**
通信、请求、登录、抢占能力全局统一；消息、好友、列表全部页面私有。

2. **完全解耦订阅模式**
页面不硬编码依赖 WS，只订阅事件，实现高可维护性。

3. **双层降级策略**
多标签抢占降级 Storage、WS 失效降级 HTTP 轮询。

4. **统一抖动退避规范**
WS 重连、Axios 重试全部采用指数退避 \+ 随机抖动，防止服务端雪崩。

## 三、核心模块详细设计

## 3\.1 全局 WebSocket 连接模块（核心重点）

### 3\.1\.1 模块职责

基于 SharedWorker 实现**浏览器全局唯一 WebSocket 长连接**，所有标签页共享同一条连接。
统一管理：握手鉴权、心跳保活、异常断开、智能重连、降级轮询、全局消息广播。

### 3\.1\.2 WS 登录鉴权机制（核心安全）

**严格实现：未登录用户无法建立任何 WS 连接**

1. **前端前置拦截**
无有效 Token 直接**不发起 WS 握手请求**。

2. **后端握手鉴权（真正拦截）**
WebSocket 握手基于 HTTP GET：

    - 后端拦截握手请求，解析 Authorization Token

    - Token 无效 / 过期 / 不存在 → 直接 401 拒绝协议升级

    - **未登录用户永远无法完成 WS 连接建立**

3. **连接持续鉴权**
后端定时校验在线用户 Token 状态，失效主动断开 WS。

### 3\.1\.3 心跳保活与断线检测

- 客户端定时 ping、服务端响应 pong

- pong 超时判定链路死亡，主动关闭连接

- 区分**优雅关闭（登出）和异常断开（网络故障）**

- 优雅关闭不重连，异常断开自动重连

### 3\.1\.4 断线重连策略（指数退避 \+ 随机抖动）

为解决大量客户端同时重连造成**服务端惊群雪崩**：

1. 重连间隔指数倍增：1s → 2s → 4s → 8s → 封顶 30s

2. 每次间隔叠加**随机抖动**打散时间

3. 最大重连次数限制，超限停止重连

4. 用户登出、Token 失效立即终止所有重连逻辑

### 3\.1\.5 WS 降级机制（HTTP 增量轮询）

**项目必备容错方案**
当出现以下场景，WS 彻底不可用：

- 浏览器不支持 WebSocket

- 防火墙拦截 WS 协议

- 持续多次重连失败

**自动降级策略：**

1. 自动切换为**HTTP 增量轮询**拉取最新消息

2. 轮询携带上次消息 ID，只拉取增量数据，性能高

3. 空消息自动拉长轮询间隔，减少服务器压力

4. 拉取到消息立即恢复高频轮询

5. **后台持续尝试恢复 WS**，一旦恢复立刻切回长连接、停止轮询

6. 轮询接口同样携带 Token 鉴权，未登录禁止访问

### 3\.1\.6 全局消息分发策略

1. Worker 收到后端消息，统一广播所有标签页

2. 聊天消息：当前会话页追加列表、非会话页弹窗

3. 系统通知、好友通知：**任何页面强制弹窗**

## 3\.2 用户登录与会话管理模块

### 3\.2\.1 登录流程

1. 账号密码请求后端

2. 后端返回 accessToken、refreshToken、用户信息

3. 前端持久化 Token

4. 自动初始化 WS 长连接、拉取好友列表

### 3\.2\.2 登出 \& 跨标签全局同步登出

基于 **StorageEvent 跨页面通信**实现：

1. 当前页面登出 → 清空本地 Token → 写入登出标记 Storage

2. 所有其他标签监听到 Storage 变更

3. 全部标签清空登录态、关闭 WS、停止轮询、跳转登录页

实现**一键登出、全浏览器所有窗口同步下线**。

### 3\.3\.1 设计策略

- **优先 SharedWorker 全局抢占**

- **浏览器不支持 Worker 自动降级 StorageEvent**

### 3\.3\.2 功能机制

1. 全局仅允许**一个活跃可操作标签页**

2. 新窗口打开自动抢占权限

3. 旧窗口自动冻结界面、禁止操作

4. 保证用户不会多窗口同时操作产生数据冲突

## 3\.6 Axios 企业级请求治理模块（完整增强版）

### 3\.6\.1 核心能力

1. **请求拦截**：统一 Token 注入、请求指纹生成

2. **响应拦截**：统一错误处理、数据剥离

3. **请求竞态取消**：相同请求未完成自动取消上一次

4. **并发队列限流**：限制最大同时请求数，防浏览器阻塞

5. **重复请求去重**：短时间相同请求合并拦截

6. **401 无感 Token 刷新**

    - 401 触发刷新

    - 刷新期间所有接口进入队列等待

    - 刷新成功批量重放请求

    - 刷新失败**全局跨标签登出**

### 3\.6\.2 新增：Axios 请求重试 \+ 指数退避随机抖动

针对网络波动、5xx 服务异常：

1. 仅对**网络异常、服务端 5xx**自动重试

2. 业务 4xx 错误不重试

3. 重试间隔指数递增 \+ 随机抖动打散

4. 最大重试次数限制
彻底解决弱网环境请求失败问题，与 WS 重连策略保持统一设计规范。

## 五、完整系统数据流

1. 项目启动 → 初始化 Axios → 初始化 Worker → 初始化抢占监听

2. 用户登录 → 存储 Token → 握手鉴权建立 WS

3. 进入聊天页 → HTTP 加载历史消息 → 订阅 WS 实时消息

4. 用户发消息 → WS 发送后端 → 后端存储转发对方

5. 对方在线实时接收、自动渲染或弹窗

6. 后端每 2 分钟推送系统时间通知

7. 网络断开 → WS 指数退避抖动重连

8. WS 彻底失效 → 自动降级 HTTP 增量轮询

9. 用户退出 → StorageEvent 全局广播 → 所有窗口下线、关闭连接
